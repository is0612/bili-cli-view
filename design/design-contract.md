## 1. 定位与平台

| 项 | 结论 |
| --- | --- |
| 用户 | 一个人用、长时间挂着的本地控制台：查视频、刷热榜、看收件箱、跑自动值班 |
| 平台 | **PC 桌面端**（Electron/Tauri/浏览器窗口），按 PC 端标准执行 |
| 断点 | 1240（概览单列 + KPI 两列）、1080（侧栏收成 64px 图标栏） |
| 密度 | 标准偏紧凑：菜单 32–34px、控件 36px、行高 32–40px |
| 个性 | 冷静的开发者工具 + 一点人味（「她今天看了什么」「值班进行中」） |

## 5. 侧栏（三段）

```
┌ 搜索 106 条命令            Ctrl K ┐   ← 搜索在侧栏顶部，不是顶栏
│ 工作台                              │
│   概览                              │   ← 视图，不是命令
│   运行记录                     12   │
│ 常用                          4 条  │
│   看懂视频 / 排行榜 / 收件箱(12) / 值班设置 │
│ 全部命令            14 组 · 106 条   │
│   ▸ 刷B站 3   ▸ 面板 1   ▸ 账号 12   │   ← 就地折叠展开
│     ▾ 发现 15                       │
│       │ 一次看完所有新消息           │   ← 子项缩进 50px + 1px 引导线
│       │ 收到的赞                     │
├ 管理菜单            收起 ┤
```

- 侧栏 **260px 贴边满高**，不做浮起白卡片。
- 分组行 34px（图标 16 + 组名 + 计数 + 折叠箭头），子项 32px。
- 选中态：`--brand-soft` 底 + `--brand-strong` 字 + 左侧 2px 竖条。
- 子项与组名**至少拉开 14px 缩进**（组名文字在 43px，子项文字在 60px），并画 1px 树形引导线。
- 1080 以下收成 64px 图标栏：只留图标，分组用细分割线区隔，计数与文案全隐藏。

## 7. 每屏结构

### 概览
```
crumb / h1（写状态：今天刷了 3 条，还剩 2 条配额）+ 刷新状态 / 现在跑一轮
KPI ×4        今日进度 | 待处理消息 | 判重跳过 | 本轮耗时
两栏 1.55fr / 1fr
  左  她今天看了什么（3 条 + 已评论 / 已投递 / 跳过标）→ 今日报告摘要
  右  快速开始（4 条命令）→ 最近运行（4 条）
```

### 命令台
```
crumb → 命令头（40px 图标 + 18px 标题 + 命令 chip + 描述）
面板：参数 2 列网格（label 12px，控件 36px，必填红星）
      sticky 操作条：命令预览 + 复制 + 安全预览 + 运行
结果：结果头（状态徽标 + 命令 + 耗时 + 复制 JSON）
      视频行：168×94 封面 / 标题 16px / 元信息 12px / hover 出复制与打开
```

### 运行记录
```
页头 + 导出 Markdown / 清空
筛选 chip：全部 12 / 成功 9 / 失败 3
列表：状态点 + 命令（等宽）+ 摘要 + 时间
```

## 8. 弹窗规范（这一版的重点）

**普通对话框，不要命令面板。**

```
┌────────────────────────────────────┐
│ 标题                   已选 x/y   × │   ← 右上角关闭
├────────────────────────────────────┤
│ [搜索框]                           │
│ 分组名  n                          │
│  ☑ 命令名                          │
│  ☑ 命令名                    写     │
├────────────────────────────────────┤
│                           [取消] [保存] │   ← 只有这两个按钮，右对齐
└────────────────────────────────────┘
```

- 尺寸：普通 520px，大 680px；最高 80vh，正文独立滚动。
- **不要**键盘上下切换提示、不要 ⌘K 面板式的快捷条。（右下角「改动清单」抽屉是评审工具，不属于产品 UI。）
- 关闭方式四种都要能关：右上角 ×、底部取消、点遮罩、Esc。
- 取消 = 丢弃草稿；保存 = 提交并 toast。
- 两个弹窗：**管理菜单**（勾选显示的命令，带搜索）、**设置**（人设 / API Key / 数据目录）。

## 9. 状态清单

| 状态 | 做法 |
| --- | --- |
| 加载中 | 骨架屏：封面块 + 三条色条，`shimmer` 1.3s |
| 空数据 | 虚线框 + 渐变色圆角图标 + 一句引导 + 一个主按钮 |
| 错误 | `--red-soft` 底 + 红描边，标题 `code：message`，第二行 `→ hint`，下面给重试 / 复制命令 |
| 写操作 | 安全预览开关默认开，命令尾部加 `--dry-run`，旁边显示琥珀色提示 |
| 运行中 | 按钮 loading + 顶栏脉冲 + 结果区骨架，三处同时给 |
| 键盘焦点 | 所有可点元素 `:focus-visible` 2px 品牌色描边 |

> 入场动画只用 `transform`，不要在 keyframes 里写 `opacity: 0 → 1`。
> 动画被暂停时（无头截图、低性能设备）元素会停在 0 透明，整个弹窗直接看不见。

| 4 | 深色模式要不要做？ | ✅ 本期不做，锁定浅色 |

**实施时发现、契约里没写到的两件事**

- **待处理消息没有数据源**：`/api/*` 里没有未读数接口，`feed.notifications` 是要现场跑的命令。
  所以这一格显示浅色「—」+ 提示「点「收件箱」拉一次才有未读数」，不编假数字。
  要把它变成真数字，得先在 `backend/app/main.py` 加一个 `/api/feed/unread` 之类的接口。
- **本轮耗时只活在内存里**：`agent._last` 是模块级变量，重启即空。文案分三种：
  有值 → 「最近一轮值班的耗时」；跑过但记录没了 → 「上一轮耗时随重启清空了」；没跑过 → 「还没有跑过值班」。

侧栏「收起」做成 64px 图标栏，**由 JS 控制而不是媒体查询**：手动点收起和窗口 <1080 要复用同一套规则，
写两次容易漏。判定在 `App.vue` 的 `rail = railManual || narrow`。

顶栏最后是三个图标按钮（扫码登录 / 刷新账号状态 / 设置），比稿上多一个 —— 稿上只画了账号 pill + 齿轮，
但登录与刷新总得有入口，HomeView 里也有一个「刷新状态」。
